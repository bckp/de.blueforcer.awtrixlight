Connect your AWTRIX pixel clock to Homey and see notifications, sensor readings and custom apps from your smart home at a glance.

Supported clocks:
- AWTRIX 3: Ulanzi TC001 (32 × 8 pixels), compatible AWTRIX 2 mainboards and self-built ESP32 matrix clocks running AWTRIX 3.
- AWTRIX NG: TC002 (52 × 16 pixels) and compatible ESP32 matrix clocks running AWTRIX NG.

Use Homey Flow to show messages, icons and custom apps, adjust brightness and control the display. TC002 also supports layouts with a title and text, audio and radio controls, script settings and data, state Flow triggers, and physical button and knob events. Available features depend on the clock and firmware.

Your clock must already run the matching AWTRIX firmware. Add AWTRIX 3 clocks using Awtrix3 and TC002/AWTRIX NG clocks using Awtrix NG.
